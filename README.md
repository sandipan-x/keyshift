# KeyShift

Transpose chords online free: shift any progression to a new key, find the easiest capo position, and score playability. With chart mode.

## Features
- Semitone stepper + key-jump panel with sharps/flats respelling
- Ranked capo finder (0–5) scored by remaining barre-prone chords
- Chart Mode: paste a full song sheet, transpose everything, copy the result
